# CST3144 After-School App - Frontend

Vue.js frontend for the CST3144 Full Stack Development coursework.

## Technology

- Vue.js 3 (via official CDN global build)
- Native JavaScript `fetch()` with Promises (no Axios)
- HTML5 + CSS3
- No build toolchain required

## Project Structure

```
frontend/
├── index.html          # Entry point with Vue 3 CDN
├── package.json        # Project metadata
├── .gitignore          # Git ignore rules
├── README.md           # This file
├── js/
│   └── app.js          # Vue 3 application instance
└── css/
    └── style.css       # Application styles
```

## Getting Started

Open `index.html` in a web browser. No installation or build step is required.

## Design

- Colors: sage green, ivory/off-white, dark charcoal/green
- Language: Neutral international English with US spelling
- Layout: Clean, professional educational booking interface

## Backend

This frontend connects to the Express.js backend API running on render.com.
The backend repository is maintained separately.
